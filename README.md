# FORTESS IT — Skills & Training App

A responsive GitHub Pages website for FORTESS IT.

## Files
- `index.html` — main app page
- `style.css` — design
- `script.js` — skills data
- `logo.png` — FORTESS IT logo

## GitHub Pages
1. Upload all files to your repository.
2. Open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select `main` and `/ (root)`.
5. Save and wait for GitHub to publish the site.

### Important
This version displays information to everyone who visits the site. The content inside `script.js` is changed by editing the file and committing the change on GitHub.

If you want a true online admin panel where you can upload/add new skills from your phone and the changes instantly appear for everyone, a database/backend (such as Firebase or Supabase) should be connected next.
